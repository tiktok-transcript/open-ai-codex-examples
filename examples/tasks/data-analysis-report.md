## Goal

Using the file DATASET_FILE (CSV), answer these three questions:

1. QUESTION_ONE
2. QUESTION_TWO
3. QUESTION_THREE

## Context

- Columns of interest: COLUMN_A (DESCRIPTION), COLUMN_B (DESCRIPTION), COLUMN_C (DESCRIPTION).
- Date column: DATE_COLUMN, format DATE_FORMAT.
- The period that matters is START_DATE to END_DATE inclusive.

## Rules for the analysis

- State every assumption you have to make about the data (missing values, duplicates, what counts as ACTIVE_DEFINITION) in a section called Assumptions. Do not choose silently.
- Show the computed table behind every number you cite.
- Use medians as well as means for anything with a long tail.
- Do not extrapolate beyond the period in the data.

## Deliverables

1. A spreadsheet named REPORT_NAME.xlsx with one sheet per question containing the computed tables.
2. A written summary of no more than 400 words with the three answers, each citing the numbers from the spreadsheet.
3. The Assumptions section at the end of the summary.

## Definition of done

All three questions are answered with a number and a one-sentence interpretation, every number in the summary appears in the spreadsheet, and the assumptions list is complete enough that someone else could reproduce the tables.
